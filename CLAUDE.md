# Gym CRM — контекст проекта

## О проекте
CRM для тренажёрного зала в Уральске. Веб-приложение (PWA), которым пользуется
администратор/ресепшен зала для учёта клиентов, абонементов, оплат и посещений.

**Перед началом любой задачи прочитай [README.md](README.md)** — там актуальная
техническая карта (структура, схема БД, известные грабли), чтобы не изучать
весь код заново.

## Стек
- Next.js (App Router, TypeScript)
- Tailwind CSS
- Supabase (база данных + авторизация + Storage) — подключено, авторизация с
  ролями admin/owner тоже готова
- Деплой: Vercel (https://gym-crm-off.vercel.app)

## Структура проекта
См. README.md — там подробная карта файлов и схема БД.

## Утверждённый функционал (MVP) — ✅ всё готово
1. **Клиенты** — карточка клиента (ФИО, телефон, дата рождения, фото), поиск и фильтр
2. **Абонементы** — типы (безлимит / N занятий / разовый), даты начала-окончания,
   статус (активен/истёк/заморожен), продление
3. **Оплаты** — сумма, дата, способ оплаты (нал/карта/Kaspi), история по клиенту
4. **Чек-ин** — отметка прихода клиента, история посещений
5. **Напоминания** — у кого абонемент истекает в ближайшие дни

## Как работать над задачами

- Не предлагать функционал вне MVP без явного запроса
- Комментарии в коде — можно на английском, тексты в UI — на русском
